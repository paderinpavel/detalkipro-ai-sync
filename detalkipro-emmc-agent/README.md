# detalkipro-emmc-agent

CLI‑агент для автоматизированного стенда диагностики eMMC в ПВЗ «ДеталькиПро».

## Назначение

Агент предназначен **исключительно для авторизованных сервисных партнёров** «ДеталькиПро» и используется в составе защищённого стенда с программатором eMMC Pro.

Функционал:
- Определение профиля чипа по модели (YAML‑профили).
- Безопасное чтение extCSD и USER‑области (только чтение).
- Хеширование дампов (SHA‑256).
- Фиксация операций в DetalkiPro Chain.
- Формирование JSON‑отчётов и артефактов для депонирования.

## Ограничения

- **Только чтение.** Операции записи, прошивки и изменения RPMB/BOOT запрещены по умолчанию.
- **Только авторизованные ПВЗ.** Использование вне экосистемы «ДеталькиПро» требует письменного согласования с автором.
- Любые публикации, интеграции и доработки вне экосистемы требуют письменного согласования с автором (Падерин П.В.).

## Депонирование

Для депонирования рекомендуется использовать архив `report-YYYYMMDD.zip`, содержащий:
- `report.json`
- `checksums.txt`
- YAML‑профили из папки `profiles/`
- Исходный код (go.mod, go.sum, *.go)
