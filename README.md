# detalkipro-partners

Парсер карточек товаров проверенных партнёров маркетплейса «ДеталькиПро».

Собирает информацию с карточек товаров на сайтах партнёров (название, цена,
описание, артикул, наличие, изображения) и выгружает CSV в формате импорта
WebAsyst Shop-Script: разделитель `;`, кодировка UTF-8, изображения — ссылками.

**Создатель и автор: Падерин Павел Владимирович**

## Возможности

- Краулер обходит весь домен партнёра от стартовой страницы: сам находит
  карточки товаров, отсекает корзину, админку и сессионные фильтры.
- Работа в 3 потока с паузами между запросами — без нагрузки на сайт партнёра.
- Ротация IP: при ответе 403/429 парсер переподключает модем
  (команда задаётся в `partners.json`) и продолжает обход.
- Реестр партнёров — конфиг, а не код: добавили партнёра в `partners.json` —
  парсер начал его собирать.
- Выгрузка `import/<partner>-<дата>.csv`, готовая к загрузке через
  «Импорт товаров из CSV» в Shop-Script.

## Структура

```
detalkipro-partners/
├── pom.xml
├── partners.json                  — реестр проверенных партнёров
└── src/main/java/pro/detalki/partners/
    ├── Main.java                  — пайплайн: конфиг → краулинг → CSV
    ├── PartnerConfig.java         — партнёр и CSS-селекторы
    ├── Product.java               — карточка товара
    ├── Crawler.java               — обход домена, карточки, защита от банов
    ├── BanException.java          — сигнал ротатору IP
    ├── IpRotator.java             — переподключение модема
    └── ShopScriptCsvWriter.java   — выгрузка в формат Shop-Script
```

## Сборка и запуск

```bash
mvn package
java -jar target/detalkipro-partners-0.1.0.jar
```

Перед запуском заполните `partners.json`: домен партнёра и CSS-селекторы
его карточек.

## Импорт в Shop-Script

Файл из папки `import/` загружается в администраторской панели:
«Импорт/Экспорт» → «Импорт товаров из CSV». Типы строк `product`,
категория с префиксом `!` создаёт подкатегорию, изображения скачиваются
по ссылкам автоматически.
